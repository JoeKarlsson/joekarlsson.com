Let's face it - managing multiple cloud environments is a headache. That's why we're so excited to announce the launch of [CloudQuery Reports](https://www.cloudquery.io/docs/platform/core-concepts/reports). We built Reports to help teams better understand and govern all of their cloud environments. Reports are an important step forward in our mission to democratize cloud visibility and control.

![CloudQuery Reports dashboard showing multiple cloud monitoring cards including Asset End of Life Report, AWS Backup Health, AWS Cloud Security, CloudTrail Log Detections, Security Best Practices, Security Hub Overview, VPC Details, Well-Architected, Azure Attack Surface, Cost Saving Opportunities, and GitHub Repository and Security Insights.](/images/blog/visualize-govern-cloud-stack-cloudquery-reports/image5.gif)

**We built Reports because:**

1. You need visibility across all your clouds without switching between five different consoles.
2. You need actionable security and compliance insights without hiring a team of experts.
3. You're probably wasting money on resources nobody remembers owning.
4. You shouldn't need a PhD in SQL to answer basic questions about your infrastructure.

## What Are CloudQuery Reports?

Think of Reports as your new command center for cloud governance. We've taken the data you're already syncing from all your cloud environments into CloudQuery and packaged it into ready-to-use dashboard that actually makes sense.

Each report comes with its own set of SQL queries that you can open right in the SQL Console or copy to your favorite BI tool. No more starting from scratch when you need to build custom dashboards.

## The Reports You Actually Need

We've organized our reports into categories that match the challenges from the biggest teams that use CloudQuery:

### Multi-Cloud Governance

![CloudQuery Reports dashboard showing a Multi-cloud asset inventory with three doughnut charts displaying resource distribution.](/images/blog/visualize-govern-cloud-stack-cloudquery-reports/image3.gif)

- Get a complete inventory of assets across all your cloud providers.
- See how your resources are tagged (or not tagged) across providers.
- Assess user access security across cloud boundaries.
- Track down public IP addresses and their connected resources.

### Cloud Security and Compliance

![CloudQuery Reports showing AWS Well-Architected security dashboard with metrics for publicly accessible resources, AWS Config compliance, and MFA adoption across cloud environments.](/images/blog/visualize-govern-cloud-stack-cloudquery-reports/image1.gif)

- Track assets nearing end of life before they become security risks.
- Get visibility into AWS Security Hub findings from one convenient location.
- Identify security risks in your AWS RDS instances.
- Stay on top of security events with CloudTrail Log Detections.
- Strengthen your attack surface management for Azure environments.

### Infrastructure and Operations

The **Asset End of Life report** helps you stay ahead of potential security and operational risks by tracking assets nearing their end of life

![CloudQuery Reports interface showing a categorized dashboard of cloud security and cost reports. The user hovers over options like 'AWS Backup Health' and 'Asset End of Life Report', each providing insights into cloud environments such as backup status, resource lifecycle, and cost optimization.](/images/blog/visualize-govern-cloud-stack-cloudquery-reports/image4.gif)

- Visualize AWS VPCs and their instances.
- Evaluate your workloads against the AWS Well-Architected Framework pillars.
- Get insights into your Kubernetes clusters across AWS EKS, GCP GKE, and Azure AKS.

### Cost Management

Find and eliminate forgotten or unused resources that are silently draining your budget with the **Cost Savings report**.

![CloudQuery Reports UI displaying a 'Cost Saving Opportunities' dashboard. It highlights unused resources like unmatched disks and public IPs across multiple cloud providers, helping teams identify cost optimization areas in a multi-cloud environment.](/images/blog/visualize-govern-cloud-stack-cloudquery-reports/image2.gif)

We've also added specialized reports for GitHub users, giving you insights into repository activity, health, and security metrics.
