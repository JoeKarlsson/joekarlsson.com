## [ChatGPT Plugins: Build Your Own In Python!](https://www.youtube.com/watch?v=hpePPqKxNq8)

_By: James Briggs_

tl;dr: OpenAI's ChatGPT has launched plugins that anyone can build. James demonstrates how to create a plugin using the chatgpt-retrieval-plugin template, which could be useful for software engineers interested in building AI-powered chatbot features.

## [Code Ownership And Software Quality](https://newsletter.getdx.com/p/code-ownership)

_By: Abi Noda_

tl;dr: Abi Noda discusses how "Ownership is negatively correlated with the number of bugs, and the more shared the file ownership the higher the likelihood that it will contain code defects." The post also explores how the number of contributors is positively correlated with the number of bugs, and provides 4 management recommendations for software engineers.

## [End of Year Pay Report 2022](https://www.levels.fyi/2022/)

_By: Levels.fyi_

tl;dr: Check out Levels.fyi's annual compensation report to get a glimpse of top paying companies, locations, growing titles, and other trends for software engineers in 2022.

## [Twintrees, Baxter Permutations, and Floorplans](https://www.youtube.com/watch?v=zg6YRqT4Duo)

_By: Donald Knuth_

tl;dr: Donald Knuth's annual lecture video connects "three fascinating concepts, which seem at first to be entirely unrelated to each other, but are in fact in one-to-one correspondence, via three beautiful algorithms." For software engineers interested in algorithms, this is a must-watch!

## [Devpod: Improving Developer Productivity at Uber with Remote Development](https://www.uber.com/us/en/blog/devpod-improving-developer-productivity-at-uber/)

_By: Uber Engineering_

tl;dr: Uber shares its experience in improving the daily edit-build-run developer experience using DevPods, their remote development environment. The blog covers initial challenges, pain points addressed, architecture, recent successes in terms of adoption and cost reduction, and thoughts about the future of remote development at Uber.

## [A Year Of Building For The Terminal](https://textual.textualize.io/blog/2022/12/20/a-year-of-building-for-the-terminal/)

_By: Darren Burns_

tl;dr: Darren reviews a year of working on cool terminal and command line tooling projects. If you're into terminals and command line tooling, you'll likely find at least one thing of interest in this post!

## [Building A Website Like It's 1999... In 2022](https://localghost.dev/blog/building-a-website-like-it-s-1999-in-2022/)

_By: Sophie Koonin_

tl;dr: Sophie Koonin reflects on the charm of personal websites from the 1990s and suggests that we've gone too far in the other direction with today's sleek, minimalist sites. She argues that old personal websites were a true reflection of oneself, making this an interesting read for software engineers building their online presence.

## [How Might Generative AI Change Programming?](https://tratt.net/laurie/blog/2022/how_might_generative_ai_change_programming.html)

_By: Laurence Tratt_

tl;dr: Laurence dives into why he thinks Generative AI (GAI) in its current form is unlikely to fully replace programming. He explores the relationship between programming and software, how GAI differs from programming when generating software, and shares some thoughts on how ML techniques might influence programming in the future.

## [Comprehensive Rust](https://github.com/google/comprehensive-rust)

_By: Google_

tl;dr: Comprehensive Rust is a course used by the Android team at Google, and it's a great resource for software engineers looking to learn Rust.

## [Clipboard](https://github.com/Slackadays/clipboard)

_By: Slackadays_

tl;dr: Clipboard allows you to cut, copy, and paste anything anywhere from the terminal, making it an extremely useful tool for software engineers working with command line interfaces.

## [Awesome ChatGPT Prompts](https://github.com/f/awesome-chatgpt-prompts)

_By: Fatih Erikli_

tl;dr: This GitHub repository curates a collection of prompts to help you use ChatGPT more effectively. It's a valuable resource for software engineers who want to get the most out of ChatGPT in their daily workflow.

## [Amazing AI Papers](https://github.com/louisfb01/best_AI_papers_2022)

_By: Louisfb01_

tl;dr: Discover the latest breakthroughs in AI research with this curated list of AI papers sorted by release date, accompanied by video explanations. This resource is perfect for software engineers and researchers interested in staying updated on cutting-edge AI developments.
