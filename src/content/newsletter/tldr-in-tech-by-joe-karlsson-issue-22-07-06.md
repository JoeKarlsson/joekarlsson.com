[tl;dr:](https://alexturek.com/2021-04-05-Writing-Descriptive-Tests/)

[The goal of testing code is both](https://alexturek.com/2021-04-05-Writing-Descriptive-Tests/)

1. [Document what the code should do](https://alexturek.com/2021-04-05-Writing-Descriptive-Tests/)
2. [Assert that it does it](https://alexturek.com/2021-04-05-Writing-Descriptive-Tests/)

[It's very common to find test that do (2) but neglect (1).](https://alexturek.com/2021-04-05-Writing-Descriptive-Tests/)

[If tests are hard to read, it has the same effect as code that's hard to read. The harder something is to understand, the harder it is to trust. The less you trust code, the harder it is to change."](https://alexturek.com/2021-04-05-Writing-Descriptive-Tests/)

[tl;dr: Principles include:](https://acjay.com/2022/03/11/11-principles-of-engineering-management/)

[1) Managing comes first, "stay out of the critical path of execution, wherever possible."](https://acjay.com/2022/03/11/11-principles-of-engineering-management/)

[2) Facilitate wellbeing so "personal safety, dignity, and wellbeing of everyone is paramount." Make sure the quiet voices are heard.](https://acjay.com/2022/03/11/11-principles-of-engineering-management/)

[3) Practice integrity. "Be transparent with information you can share. Be transparent about when you cannot do something. Keep your commitments. Own up to your mistakes." And more.](https://acjay.com/2022/03/11/11-principles-of-engineering-management/)
