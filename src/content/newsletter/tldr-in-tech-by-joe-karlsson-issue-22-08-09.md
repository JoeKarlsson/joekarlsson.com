[tl;dr: "One of the fun examples among all the copyright fuss is the extreme example of copyright claims made by AT&T some time in the 1980s. It's the /bin/true program. This is a "dummy" program whose function is to make it easy to write infinite loops in shells scripts. The program does nothing; it merely exits with a zero exit status... But AT&T's lawyers decided that this was worthy of copyright protection."](http://trillian.mit.edu/~jc/humor/ATT_Copyright_true.html)
