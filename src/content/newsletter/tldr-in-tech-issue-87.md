## [Architects, Anti-Patterns, and Organizational Fuckery](https://charity.wtf/2023/03/09/architects-anti-patterns-and-organizational-fuckery/)

_By: Charity Majors_

tl;dr: Charity Majors asserts that "only the people responsible for building software systems get to make decisions about how those systems get built." The presence of an architect can cause decision-making to become "someone else's problem," leading to weaker engineers and worse systems. Charity discusses how to effectively utilize architects in your organization.

## [Lessons From A Pessimist: Make Your Pessimism Productive](https://lucumr.pocoo.org/2023/3/20/lessons-from-a-pessimist/)

_By: Armin Ronacher_

tl;dr: Armin Ronacher distinguishes between pragmatic pessimism and destructive pessimism. While pragmatic pessimism can be useful, assuming things are more difficult than they really are, destructive pessimism wants or expects things to fail and can be harmful. Embrace the former and avoid the latter for a healthier engineering mindset.

## [Keeping The Cloudflare API 'All Green' Using Python-Based Testing](https://blog.cloudflare.com/keeping-cloudflare-api-all-green-using-python-based-testing/)

_By: Elie Mitrani_

tl;dr: Elie Mitrani presents Scout, an automated Python testing system that verifies Cloudflare's APIs in production-like environments. Scout helps green-light production deployments and monitors API behavior. A fascinating read for software engineers interested in Python-based testing and API management.

## [Eight Graphs That Explain Software Engineering Salaries In 2023](https://spectrum.ieee.org/software-salaries-2023)

_By: Tekla Perry_

tl;dr: Tekla Perry analyzes 2022 data to reveal trends in software engineering salaries, including rising tech salaries (but below inflation), best-paying jobs, skills employers want, and skills by demand. A valuable resource for software engineers looking to understand the job market and plan their careers.

## [Why People Misuse Inheritance](https://solicited-thoughts.bearblog.dev/why-people-misuse-inheritance/)

_By: Unknown_

tl;dr: The author argues that people often misuse inheritance because it feels like less work to implement and maintain compared to composition or delegation-based approaches. However, the inheritance-based approach is often either incorrect or a "subtle bug waiting to happen." Food for thought for software engineers striving for better design practices.

## [The Curious Case Of A Memory Leak In A Zig Program](https://iamkroot.github.io/blog/zig-memleak)

_By: Krut Patel_

tl;dr: Krut Patel shares an unexpected "memory leak" encountered when writing a Zig program. The focus is on a simple allocation pattern that causes a "leak" when using a particular allocator from Zig's stdlib. A captivating read for software engineers interested in memory management and Zig programming.

## [Commandlinefu](https://www.commandlinefu.com/commands/browse)

tl;dr: Commandlinefu is a treasure trove of command-line gems that users can record, share, comment on, discuss, and vote up or down. It's an excellent resource for software engineers looking to expand their command-line wisdom and learn from the experience of others.
