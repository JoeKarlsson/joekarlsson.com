**[tl;dr](https://buttondown.email/hillelwayne/archive/regexes-are-cool-and-good)**[: People hate regexes for 2 reasons:](https://buttondown.email/hillelwayne/archive/regexes-are-cool-and-good)

[1) They're hard to read, so it's hard to tell what a regex does.](https://buttondown.email/hillelwayne/archive/regexes-are-cool-and-good)

[2) They're fragile an a slight change to the input can break it and making them more robust is tough.](https://buttondown.email/hillelwayne/archive/regexes-are-cool-and-good)

[Hillel argues that the best use cases for regexes is in "interactive use" - when you're trying to substitute in a single file you have open, or grep a folder. "Readability doesn't matter because you're writing a one-off throwaway, and fragility is fine because you're a human-in-the-loop."](https://buttondown.email/hillelwayne/archive/regexes-are-cool-and-good)
